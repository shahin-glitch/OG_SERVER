# OG SURFER 
Created a game using Three.js and WebGL. The game is a simple endless runner where the player controls a surfer riding waves, avoiding obstacles, and collecting power-ups.

Instructions:
- Use the arrow keys or WASD to move left and right.
- Press the spacebar or up arrow to jump.   

Includes a scoring system, lives, and power-ups. The game ends when the player loses all their lives.

Made with Three.js, WebGL, and JavaScript. The game features a dynamic environment with waves, obstacles, and power-ups. The player can collect points by avoiding obstacles and collecting power-ups.

Complete the game by achieving the highest score possible before losing all lives💚💚💚.
